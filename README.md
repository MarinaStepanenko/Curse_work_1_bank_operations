## Описание проекта

Приложение для анализа банковских транзакций из Excel-файлов. Генерирует JSON-данные для веб-страниц, формирует Excel-отчеты и предоставляет различные сервисы анализа финансовых данных.

## Описание данных

Файл `operations.xlsx` содержит следующие колонки:

- **Дата операции** - дата транзакции
- **Дата платежа** - дата платежа  
- **Номер карты** - последние 4 цифры номера карты
- **Статус** - статус операции (OK, FAILED)
- **Сумма операции** - сумма в оригинальной валюте
- **Валюта операции** - валюта транзакции
- **Сумма платежа** - сумма в валюте счета
- **Валюта платежа** - валюта счета
- **Кешбэк** - размер кешбэка
- **Категория** - категория транзакции
- **MCC** - код категории
- **Описание** - описание транзакции
- **Бонусы** - количество бонусов
- **Округление на «Инвесткопилку»** - сумма округления
- **Сумма операции с округлением** - округленная сумма

## Модуль reports.py

### Декоратор для отчетов

```python
def write_in_file(filename: str = "reports.csv") -> Callable:
    """
    Декоратор принимает аргумент filename, который определяет,
```


## Установка и запуск

1. Установите зависимости:
```bash
poetry install
```
2. Настройте переменные окружения в `.env`

3. Запустите приложение:
```bash
python src/main.py
```
4. Запустите тесты:
```bash
pytest tests/
```
## API сервисы

Для получения данных о валютах и акциях используются внешние API:

- Курсы валют: выбранный финансовый API
1. Получить API-ключ на [apilayer.com](https://apilayer.com/marketplace/exchangerates_data-api)
2. Создать файл `.env` в корне проекта
3. Добавить в файл `.env` ваш API-ключ:

```text
API_KEY=ваш_ключ_здесь
```
- Цены акций: выбранный биржевой API
1. Установка Twelve Data API
2. Установка через pip

```bash
pip install twelvedata
```
3. Регистрация на Twelve Data:

Перейдите на twelvedata.com

Зарегистрируйте аккаунт

Получите бесплатный API ключ в личном кабинете

Бесплатный план: 800 запросов в день, 8 запросов в минуту

4. Настройка API ключа

Добавьте в файл .env:

```env
API_KEY_TWELVEDATA=your_api_key_here
```
